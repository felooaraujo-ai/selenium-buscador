# Buscador de clientes · Selenium Systems

Encuentra talleres de muebles, carpinterías y mueblerías por zona usando OpenStreetMap, arma una lista de contactos con estados y notas, y prepara el mensaje para mandar de a uno.

En línea: https://felooaraujo-ai.github.io/selenium-buscador/

El código de trabajo y las notas de aprendizaje están en el repo `trabajos-personales` (`experimentos/buscador-clientes`).
